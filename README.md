# thevahidal/tap

Homebrew tap for [Notchkeeper](https://github.com/thevahidal/notchkeeper) (formerly Ping), your Claude Code agents in the MacBook notch.

```bash
brew trust --cask thevahidal/tap/notchkeeper && brew install --cask thevahidal/tap/notchkeeper
```

Had `ping` installed? `brew upgrade` moves you to `notchkeeper`.
